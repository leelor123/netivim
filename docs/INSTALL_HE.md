# התקנה ועדכון של נתיבים בטלפון

## התקנה ראשונה
1. מורידים בטלפון את הקובץ: https://github.com/leelor123/netivim/releases/latest/download/netivim.apk
2. פותחים את הקובץ. אם מופיע "התקנה ממקור לא ידוע": הגדרות, להפעיל "אפשר ממקור זה", ולחזור.
3. לוחצים "התקן" ואז "פתח". (אם Play Protect שואל: "התקן בכל זאת".)

## עדכונים אוטומטיים עם Obtainium (פעם אחת בלבד)
1. מתקינים את Obtainium: https://github.com/ImranR98/Obtainium/releases/latest
   (מורידים את הקובץ שמסתיים ב־arm64-v8a-release.apk ומתקינים כמו בסעיף הקודם.)
2. פותחים את Obtainium, לוחצים "Add App", מדביקים את הכתובת https://github.com/leelor123/netivim ולוחצים "Add".
3. מאשרים ל־Obtainium לשלוח התראות. מעכשיו, כשיוצאת גרסה חדשה, מגיעה התראה, ולחיצה על "Update" מתקינה אותה מעל הקודמת.

השמירות במשחק נשמרות בכל עדכון. אל תמחקו את המשחק לפני עדכון.
